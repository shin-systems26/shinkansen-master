# 🚅 SHINKANSEN MASTER

新幹線の運転をブラウザ上で体験できるWebシミュレーターです。

姫路から新大阪まで、新幹線を運転しながら各駅への停車を目指します。

## 🎮 主な機能

- 新幹線の加速・減速操作
- ATCによる速度制限
- 駅への停止位置判定
- 到着時刻による評価
- 運転スコア
- 車内案内表示
- 車内放送
- トンネル・カーブなどの走行演出
- 運転席視点の3D表示

## 🕹️ 操作方法

- ↑ / ↓：マスコン操作
- Space：警笛
- C：カメラ切り替え
- P / Esc：一時停止
- F：フォト機能
- M：プレミアムUI
